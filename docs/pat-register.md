# ทะเบียน Personal Access Token (งาน D2)

เอกสารนี้เป็นทะเบียนเท่านั้น — **ห้ามบันทึกค่า token ในไฟล์นี้หรือในแชท** ให้บันทึกชื่อและวันหมดอายุ เพื่อให้รู้ว่าต้องหมุนเมื่อไร

## 1. กติกา

1. หนึ่งเครื่องต่อหนึ่ง PAT (Fine-grained) · Repository access = เฉพาะ `Thaidimaru/Pre_PM2` · Permissions = **Contents: Read and write** เท่านั้น
2. Expiration ไม่เกิน 90 วัน · ตั้งชื่อ `prepm-field-<ชื่อเครื่องหรือผู้ใช้>`
3. เครื่อง admin ที่รัน `database.py` ใช้ PAT แยกอีกอัน (ไม่ใช้ร่วมกับเครื่องภาคสนาม)
4. เมื่อหมดอายุ: เปิดแอป → Navbar → ตั้งค่า Token → วางค่าใหม่ · แล้วอัปเดตตารางนี้
5. เมื่อ suspect ว่าหลุด: revoke ทันทีที่ https://github.com/settings/personal-access-tokens และเปิดงานตรวจสอบ

## 3. การแจ้งเตือนหมดอายุ

- P3 ตรวจตารางนี้ทุกเดือน และเริ่มหมุนเมื่อเหลือไม่เกิน 14 วัน
- แอปจะแจ้งเตือนเมื่อ token ใช้ไม่ได้ (401) ผ่าน `GitHubTokenModal` และ toast — ข้อมูลจะค้างใน `localStorage` และซิงค์ต่อเมื่อใส่ค่าใหม่
